Spam/Ham Message Classifier

Project Overview

This machine learning project classifies SMS messages into Spam and Ham (legitimate messages).

Technologies Used

- Python
- Google Colab
- Pandas
- Scikit-learn
- Matplotlib

Machine Learning Algorithms and Techniques

- TF-IDF text feature extraction
- Multinomial Naive Bayes
- Train-test split
- Accuracy, precision, recall, F1-score
- Confusion matrix

Dataset

SMS Spam Collection dataset from the UCI Machine Learning Repository.

Project Workflow

1. Load the dataset.
2. Explore and clean the data.
3. Split data into training and testing sets.
4. Convert text into TF-IDF features.
5. Train the classifier.
6. Evaluate model performance.
7. Test custom messages.

How to Run

Open "spam-ham-classifier.ipynb" in Google Colab and run the notebook cells in order.
